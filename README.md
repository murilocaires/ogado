# Bovaro

**Bovaro** é uma aplicação web para gestão de recria, compra e venda de gado, com foco em cálculo preciso e tomada de decisão baseada em dados.

## Sobre o produto

O Bovaro ajuda pecuaristas a simular e acompanhar operações de recria e comercialização, calculando resultados com base em planilhas consolidadas e regras de negócio validadas. A aplicação foi pensada para uso no campo e na gestão, com interface simples e cálculos confiáveis.

## Funcionalidades

- **Painel** — Visão geral das operações e indicadores principais
- **Compra e Venda** — Cadastro e acompanhamento de lotes com cálculos de valor, peso e margem
- **Recria** — Simulação e acompanhamento da recria com divisão por custos, receita e resultado
- **Cenários** — Criação, comparação e análise de diferentes cenários para apoiar decisões
- **Sincronização** — Sincronização entre dispositivos com suporte offline
- **Autenticação e conta** — Acesso seguro com gerenciamento de conta
- **PWA instalável** — Pode ser instalado como aplicativo no celular ou desktop

## Tecnologias

- **Frontend:** Next.js (React) + TypeScript
- **Backend:** Fastify + TypeScript
- **Banco de dados:** PostgreSQL + Prisma
- **Monorepo:** pnpm workspaces
